---
title: "Comment on code lines"
platform: [desktop]
---

In any diff or code view — an Edit in the chat, the Files tab, a Git commit —
hover over a line number and click the **+** in the gutter to attach a note to
that exact line.

Your notes show as indicators on the related messages and commits. Use **Add
to message** to drop a comment (with its line) into the composer — or add them
all at once.
