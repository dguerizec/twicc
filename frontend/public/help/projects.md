---
title: "Working with projects"
---

A project is a **working directory** where agent sessions run — one project per
folder. TwiCC creates one automatically for every folder that has sessions,
including sessions you ran with Claude Code or Codex **outside** TwiCC. You can
also add a project yourself by pointing TwiCC at a folder.

### What TwiCC keeps under a project

Every session that runs in that folder is grouped under the project — so you can
find your work by where it happened.

### Make it yours

Give a project a **name** and **color**, and set **per-project defaults**
(provider, agent settings, default layout) that seed every new session you start
there.

Naming also orders the home list: **named** projects sit at the top as cards, so
your important ones are easy to reach, while **unnamed** ones are listed below,
grouped into a folder tree by their paths.

### Organizing

Group related projects into a [workspace](help/workspaces). And a git repo's
[worktrees](help/worktrees) show up as their own projects, linked back to it —
so opening a project also lists its worktrees' sessions, with a badge to tell
parent and worktree sessions apart.

### Archiving

Done with a project? **Archive** it — it's hidden from the lists, but nothing is
deleted and its sessions stay searchable. Archive it from its edit dialog, or
from its **⋯** menu in the project selector at the top of the sidebar. To see
archived projects again, tick **Show archived** on the home's Projects section;
from there you can **unarchive** any of them.
