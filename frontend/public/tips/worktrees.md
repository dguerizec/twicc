---
title: "Start a session in a new worktree"
---

Click the **New session** button — git projects in the list show a worktree
button (a branch icon with a **+**). Click it to create a git worktree, on a
new or existing branch, and open a session right inside it.

The worktree is automatically linked to its parent project, so its sessions
roll up under the main repo.
