---
title: "Choose where worktrees go by default"
---

Tell TwiCC where to put new git worktrees: a base directory relative to each
project's git root (e.g. `.worktrees`, or `../` to sit beside the repo). The
worktree dialog then pre-fills the path from it — you can still change it each
time.

Set it in **Settings → Global → Default worktree directory**, and override it
per project from that project's edit dialog.
