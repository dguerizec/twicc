---
title: "Use ⌥ as Meta in the terminal"
os: [mac]
---

Prefer Emacs-style word movement in your shell? In **Settings → Terminal**,
enable **Option key → Use as Meta** so **⌥B / ⌥F** move word by word (and
**⌥.** inserts the last argument).

The trade-off: characters typed with Option — like `|`, `{` or `\` on some
layouts — stop working, so leave it off if you rely on those.
